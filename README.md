Macro Commander 3.3.5a

This is a Macro Linking UI, letting you to link your wow built in macros to a button list to save action bar space, there many options, use '/macroc help' to see supported commands

The Macro name box also accepts slash commands (/test) and server commands (.sr bot-setting). No separate Ace3 addon is required.

client support: wotlk 3.3.5a
